# CasaContas

CasaContas organiza, divide e acompanha despesas de casas compartilhadas com exatidão de centavos, isolamento entre casas e trilha de auditoria.

## Status

MVP v0.1.0 em implementação. O repositório usa um monólito modular Java 21/Spring Boot 4, um frontend React/TypeScript e PostgreSQL. A licença ainda depende de uma decisão explícita do proprietário.

## Estrutura planejada

- `backend/`: API REST, domínio financeiro e persistência.
- `frontend/`: aplicação web React responsiva.
- `docs/`: requisitos, ADRs, arquitetura, operação e evidências.
- `.github/`: governança, CI, segurança e entrega de imagens.

O plano verificável está em `docs/implementation/EXECUTION_PLAN.md`. As instruções completas de execução serão atualizadas junto com as primeiras fatias funcionais.
